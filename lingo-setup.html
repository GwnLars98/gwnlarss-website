Lingo

Vul je Twitch-gebruikersnaam in. De bot joint dan meteen jouw chat en start een ronde: chat raadt samen een Nederlands woord van 5 letters, elke gok (gewoon het hele woord typen, geen commando nodig) krijgt groen/geel/grijs-feedback terug. Het linkje hieronder gebruik je als Browser Source in OBS voor het bord.

Zit de bot al in je chat? Vul gewoon je naam in en klik nog eens op Activeer, dat kan geen kwaad. Je kan ook meteen het linkje hieronder als Browser Source toevoegen (met ?kanaal=jouw-naam erachter) zonder hier eerst op Activeer te klikken, de overlay activeert Lingo dan zelf zodra 'ie geladen wordt.

  1. Open OBS, voeg een nieuwe Browser Source toe.
  2. Plak het linkje hierboven als URL.
  3. Typ een 5-letterwoord (zonder iets erbij) in je eigen chat om te testen.
  4. Chat heeft samen 5 pogingen per ronde, daarna start automatisch een nieuwe ronde met een nieuw woord.
